criteria: "어느 시점에 프로세스나 전원이 죽어도, 저장된 재개 위치가 아직 안전하지 않은 데이터를 앞지르지 않는가?"
---
통과: 원본 파일 읽기 위치는 해당 줄이 디스크 버퍼에 쓰이고 fsync 된 뒤에만 저장한다. 버퍼 전송 위치는 서버 200 을 받은 뒤에만 저장하고, 4개 동시 전송에서는 앞선 배치가 모두 확인된 연속 구간까지만 전진한다. 위치 파일은 임시 파일 쓰기, fsync, rename 순서로 교체한다. rename 뒤 디렉터리 fsync 는 없어도 된다 (옛 위치로 돌아가 중복만 생긴다). 실패: 읽거나 큐에 넣은 시점에 위치를 저장하거나, 뒤 배치가 먼저 끝났을 때 그 위치로 전진해 앞 배치 실패 시 유실되거나, 버퍼 fsync 없이 원본 위치를 저장하거나, 위치 파일을 제자리에서 덮어쓴다.
