criteria: "에이전트가 실행 중이든 꺼져 있든, 로테이션 뒤에도 같은 파일을 정확히 식별해 줄 손실이나 파일 전체 재전송 없이 이어 읽는가?"
---
통과: 파일 식별자에 inode 와 함께 파일 앞부분 지문이 들어간다. create 방식에서는 옛 파일 핸들을 끝까지 읽은 뒤 새 파일로 넘어간다. 재시작 시 저장된 파일이 경로에 없으면 .1 같은 회전 파일에서 찾아 남은 부분을 읽는다. copytruncate 는 크기가 저장 위치보다 작아지거나 지문이 달라지면 0부터 읽는다. 실패: 체크포인트 식별자가 경로 또는 inode 뿐이라 inode 재사용을 구분하지 못하거나, 경로의 inode 변경을 보고 옛 파일의 남은 줄을 버리거나, 재시작 때 경로의 현재 파일만 보아 꺼져 있는 동안 회전된 파일의 나머지를 놓치거나, 크기가 줄어도 저장 위치에서 계속 읽는다.
