Go 또는 Python 으로 Linux 호스트에서 도는 로그 수집 에이전트의 핵심 코드를 구현해 주세요. 파일을 쓸 도구가 없으니 답변 본문에 코드를 적어 주세요. 핵심 코드는 200줄 이내로 하고, HTTP 전송 클라이언트와 설정 파싱은 인터페이스만 적어도 됩니다.

입력:
- /var/log/app/ 아래 로그 파일 20종을 줄 단위로 읽습니다. 앱은 계속 씁니다.
- 일반 서비스의 logrotate 설정은 size 500M, rotate 3, compress, delaycompress, create 입니다.
- 레거시 서비스의 logrotate 설정은 size 500M, rotate 3, copytruncate 입니다.

출력:
- 줄을 배치로 묶어 수집 서버에 HTTPS 로 보냅니다.
- 수집 서버는 저장을 마치면 200 을 응답하고, 같은 batch_id 는 중복 제거합니다.
- 처리량 때문에 배치는 최대 4개까지 동시에 전송합니다.
- 수집 서버가 멈춰도 로그를 잃지 않도록 디스크 버퍼를 둡니다.

운영 요구사항:
- 에이전트는 배포, OOM, 전원 차단으로 언제든 죽을 수 있고 몇 시간 꺼져 있기도 합니다.
- 다시 켜지면 멈춘 곳부터 이어서 보내야 합니다. 일부 중복은 괜찮지만 줄이 빠지거나 파일 전체를 다시 보내면 안 됩니다.
- 수집 서버 장애는 며칠까지 이어질 수 있습니다.
- 호스트 디스크는 앱과 함께 씁니다. 에이전트 때문에 늘어나는 디스크 사용량은 2 GiB 이내여야 합니다.
- 더 보관할 수 없으면 로그 일부를 포기해도 되지만, 포기한 양을 지표로 남겨야 합니다.
