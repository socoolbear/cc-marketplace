---
type: llm
criteria: "단말이 올린 데이터가 서버 장애·재시작 때 유실되거나 재전송으로 중복 저장되지 않도록, 확인 응답 시점과 중복 제거를 설계하는가?"
---
통과: 서버가 데이터를 DB 또는 내구성 있는 저장소에 기록한 뒤에만 단말에 확인 응답을 보내고, 단말은 확인 응답을 받을 때까지 데이터를 보관했다가 재전송하며, 단말 ID + 시퀀스 번호 같은 멱등 키로 재전송분의 중복 저장을 막는다는 내용을 모두 제시한다. 실패: 메모리 큐·버퍼에 넣은 시점에 확인 응답을 보내거나, 확인 응답 시점을 다루지 않거나, 재전송만 말하고 중복 저장 방지가 없거나, TCP 전송 성공을 저장 성공으로 취급한다.
