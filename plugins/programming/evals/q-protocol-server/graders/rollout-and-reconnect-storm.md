---
type: llm
criteria: "Kubernetes 배포나 Pod 장애로 수만 개 연결이 끊겨도 처리 중 데이터를 잃지 않고 재연결 폭주로 인한 연쇄 장애를 막도록 설계하는가?"
---
통과: SIGTERM 을 받으면 신규 연결을 막고, 처리 중 데이터 저장을 마친 뒤 기존 연결을 서버가 직접 나눠서 닫으며, 이 과정이 terminationGracePeriodSeconds 안에 끝나도록 맞춘다. 또한 단말 재연결에 지수 백오프와 무작위 지터를 적용하고, 서버 측에서 연결 수락 속도나 인증 처리량을 제한한다는 내용을 모두 제시한다. 실패: 기본 롤링 업데이트에만 맡기거나, readiness 실패만으로 기존 TCP 연결까지 정리된다고 보거나, 단말의 고정 간격·즉시 재연결을 방치하거나, 서버 측 재연결 유입 제한이 없다.
