통과: 단말-인스턴스 연결 위치를 TTL·임대 방식의 공유 저장소나 pub/sub 등으로 찾아 명령을 해당 인스턴스로 라우팅하고, 재연결 때 이전 세션과 위치 정보를 대체하며, 명령을 영속 저장한 뒤 단말의 확인 응답으로 완료를 판정하고 오프라인·미응답 명령은 재전달하거나 만료 처리한다는 내용을 모두 제시한다. 실패: 요청을 받은 인스턴스가 자기 메모리의 연결만 찾거나, 낡은 위치 정보의 정리 방법이 없거나, 소켓 쓰기 성공을 전달 완료로 취급하거나, 오프라인 단말의 명령 처리를 다루지 않는다.
