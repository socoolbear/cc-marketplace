---
type: llm
criteria: "수신을 멈춘 채 ping 만 보내는 클라이언트를 송신 정지로 감지해 끊고, 송신 프레임 경계를 깨뜨린 채 이어 쓰지 않는가?"
---
통과: 쓰기 제한 시간이나 송신 진행 감시 (SetWriteDeadline, wait_for(drain), drain 이벤트 타이머 등) 가 조용한 토픽에서도 동작하고, 초과하면 연결을 닫는다. 쓰기 제한 시간 초과 뒤 그 연결에 다음 프레임을 쓰지 않는다. 연결당 쓰기 주체가 하나이거나, 프레임 전체를 끼어들 수 없는 단위로 쓴다. 실패: 감지 수단이 수신 유휴 타이머나 TCP keepalive 뿐이거나, 큐 초과로만 끊어서 조용한 토픽의 정지 연결이 영원히 남거나, 쓰기 제한 시간 초과 뒤 다음 프레임을 이어 쓰거나, 여러 실행 흐름이 헤더와 본문을 나눠 같은 소켓에 쓴다.
