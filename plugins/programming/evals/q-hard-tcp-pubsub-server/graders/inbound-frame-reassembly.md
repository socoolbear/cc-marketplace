---
통과: 헤더나 본문이 여러 번에 나뉘어 와도, 한 번에 여러 프레임이 와도 처리한다 (io.ReadFull, readexactly, 누적 버퍼 파싱 등). 본문을 할당하거나 쌓기 전에 길이를 검사해 256 KiB 초과면 연결을 끊는다. 90초 판정은 바이트 도착이 아니라 완성된 프레임 기준이다. 실패: 읽기 한 번을 프레임 하나로 가정하거나, Node 의 data 이벤트를 이어 붙이지 않고 파싱하거나, 길이 검사 전에 선언 길이만큼 할당하거나, 바이트가 올 때마다 유휴 타이머를 갱신해 1바이트씩 보내는 연결이 살아남는다.
