Go, Python asyncio, Node.js 중 하나로 아래 TCP 서버의 핵심 코드를 구현해 주세요. 파일을 쓸 도구가 없으니 답변 본문에 코드를 적어 주세요. 핵심 코드는 200줄 이내로 합니다. 인증과 토픽 저장소는 생략해도 됩니다.

프로토콜:
- 프레임은 4바이트 big-endian 길이 뒤에 JSON 본문이 오는 형식입니다.
- 본문은 보통 1 KiB 정도이고 최대 256 KiB 입니다.
- 클라이언트가 보내는 프레임은 subscribe, publish, ping 이고, ping 은 30초마다 보냅니다.
- 서버가 보내는 프레임은 message (seq 포함), pong, ack 입니다.

서버 요구사항:
- 프로세스 하나가 동시 연결 5,000개를 처리하고, 메모리 제한은 4 GiB 입니다.
- publish 된 메시지는 해당 토픽의 모든 구독자에게 보냅니다. 토픽 하나의 구독자는 최대 5,000명이고 초당 최대 200건이 publish 됩니다. 어떤 토픽은 몇 시간씩 조용합니다.
- 클라이언트의 회선 품질은 제각각입니다.
- 정상 클라이언트에게는 publish 후 200ms 안에 전달해야 합니다.
- 연결이 유지되는 동안 클라이언트는 seq 가 빠지지 않고 순서대로 받아야 합니다. 연결이 끊기면 클라이언트가 재접속해 마지막 seq 이후를 받습니다. 재접속 복구는 이번 범위가 아닙니다.
- 서버는 90초 동안 완성된 프레임을 하나도 받지 못한 연결을 끊습니다.
