통과: preStop sleep 또는 앱 내부 지연으로, 종료 시작 뒤 5초 이상 HTTP 리스너가 새 연결을 받은 다음 닫는다. 작업이 없는 유휴 상태에서도 이 대기가 적용된다. 실패: TERM 을 받자마자 리스너를 닫거나, 작업이 없으면 대기 없이 바로 닫거나, readiness 를 실패로 바꾸면서 곧바로 리스너를 닫거나, sleep 실행 파일이 없는 이미지에서 exec 방식 sleep 을 쓴다.
