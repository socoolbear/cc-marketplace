Go, Python, Node.js 중 하나로 아래 워커를 구현하고 Kubernetes 배포 설정까지 작성해 주세요. 파일을 쓸 도구가 없으니 답변 본문에 코드를 적어 주세요. 핵심 코드는 전체 200줄 이내로 합니다.

워커 동작:
- 큐 클라이언트의 receive() 로 작업을 하나씩 받아 처리하고, 끝나면 ack(id) 를 호출합니다. 큐 클라이언트는 이미 있다고 가정합니다.
- 작업은 보통 수 초, 최대 120초 걸립니다. 외부 시스템을 호출하므로 도중에 끊기면 안 됩니다.
- 같은 프로세스가 8080 포트에서 작업 상태 조회 HTTP API 를 제공합니다. 클러스터의 Service 와 Ingress 뒤에 있습니다.

컨테이너 시작 스크립트:
- entrypoint.sh 가 /etc/app/env 를 source 한 뒤 앱을 실행합니다.
- 앱이 끝난 뒤 /usr/local/bin/flush-metrics 를 실행합니다. 최대 5초 걸리고 컨테이너가 종료될 때마다 실행돼야 합니다.
- 컨테이너 종료 코드는 앱의 종료 코드와 같아야 합니다.

운영 요구사항:
- replicas 는 3 입니다.
- 롤링 배포와 노드 드레인 중에도 처리 중인 작업이 잘리지 않아야 하고, 상태 조회 요청이 실패하지 않아야 합니다.

제출물: Dockerfile, entrypoint.sh, 앱 핵심 코드, Deployment YAML
