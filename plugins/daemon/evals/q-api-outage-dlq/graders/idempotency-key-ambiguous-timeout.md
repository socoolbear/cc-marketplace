type: llm
criteria: "타임아웃·재시도·재처리로 같은 이벤트가 파트너에게 두 번 전달될 수 있음을 다루고 멱등 키 등으로 중복 부작용을 막는가?"
---
타임아웃은 파트너 쪽 성공일 수도 있어 재시도하면 이중 전달이 되고, 커밋 전 크래시·리밸런스·DLQ 재처리도 같은 이벤트를 다시 보낸다. 통과: 이벤트 ID 를 `Idempotency-Key` 헤더 등으로 보내 파트너가 중복을 거르게 하거나(지원 여부 확인 포함), 파트너가 지원하지 않으면 송신 이력 저장·조회로 중복을 줄이는 방안을 제시한다; 순서가 중요한 키는 재시도·DLQ 재처리 때 순서가 깨질 수 있음을 함께 다루면 가점이다. 실패: 재시도·재처리 설계만 있고 중복 전달 가능성을 전혀 언급하지 않는 경우.
