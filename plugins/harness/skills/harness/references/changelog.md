# 변경 이력

maintain 이 마커 `version` 보다 새로운 항목을 점검 보고 첫머리에 한 줄씩 알린다. 설치된 프로젝트에 영향이 있는 변경만 적는다 (최신이 위).

## 4.2.0

- maintain 이 검증 명령을 다시 수집해 AGENTS.md 에 없는 것을 추가 후보로 보고한다
- 마지막 승격 시각을 마커 `lastReflect` 대신 머신별 memory 디렉토리에 기록한다 — 다른 머신의 승격 때문에 이 머신의 학습이 빠지지 않는다. 기존 `lastReflect` 는 기준값으로만 읽으므로, 4.1 이하를 쓰는 팀원이 계속 커밋하면 기준이 앞당겨질 수 있다
- LESSONS 등재 후에도 같은 실수가 재발하면 "등재 후 재발 N회" 로 보고하고 검사 전환·문구 재작성을 권고한다

## 4.1.0

- 학습 승격이 memory 의 `발생:` 날짜로 재발 횟수를 센다 — 서로 다른 날 2회부터 LESSONS 후보. 사용자가 명시적으로 지시한 것은 1회라도 후보
- 이미 린터·테스트·훅이 잡는 학습은 등재하지 않고, 검사가 없으면 추가를 함께 권고한다

## 4.0.0

- 모드를 setup / maintain 두 개로 정리 (reflect 는 maintain 의 학습 승격 단계)
- 세션 시작 훅이 골격 갱신·승격 대기 학습·깨진 지도 포인터를 감지해 점검을 제안한다
- 레이어 검사 훅을 팀 공유 `.claude/settings.json` 에 등록한다 (v3 의 `settings.local.json` 훅은 maintain 이 이관 후보로 보고)
